# 桥梁热响应预测：本地代码与图件整理包

对应当前 Information Fusion 稿件，共整理 **9张论文图**。本目录是后续上传个人 GitHub 的本地项目，当前尚未上传。

压缩包上传步骤见 [UPLOAD.zh-CN.md](UPLOAD.zh-CN.md)。下文的 `local_assets/` 只存在于本地工作目录，不包含在上传包中。

代码已清除原机器路径、账号、硬件型号和已保存的进程编号，并统一通过 `tools/run_experiment.py` 配置运行。使用方法见 [运行配置说明](docs/RUNTIME.md)。D1归一化统计量已改为私有输入引用，具体值不包含在上传包中。

## 从哪里开始

- `figures/`：按当前论文图1—图9编号的最终图，全部含PDF和PNG；数据图另含SVG。
- `plotting/`、`tools/render_figures.py`：可在本目录执行的数据图绘制代码。
- `experiments/`：按实验职责划分的模型、训练、评价、配置及依赖源码。
- `results/manuscript_tables.json`、`.tex`：整理时当前主稿的全部表格；其他文件为对应结果汇总。
- `experiments/d2_pipeline/data/minute_synthetic.npz`：完整D2合成数据集，400天、分钟级、8通道，训练/验证/测试为280/60/60天；该目录的 `README.md` 说明字段和读取方式。
- `docs/EXPERIMENTS.md`：每项实验的入口、实际协议和所需输入。
- `docs/DATA.md`：数据字段、样本范围、划分和读取示例。
- `local_assets/`：只保存在电脑上的原始冻结代码、源路径清单、绘图缓存和可编辑PPT/SVG，已被Git忽略。

本地重绘命令：

```powershell
python tools/render_figures.py --figure all
```

产物写入 `outputs/figures/`，不会覆盖 `figures/` 中从论文复制的最终图。也可以用 `--figure 5` 单独重绘一张。图1—图4来自编辑后的示意图文件，保留原PDF；未虚构一套不存在的自动生成代码。

## 实验版本

1. **D1完整测试期**：五个独立PRFM与对应STPM种子配对；109测试日，RMSE为16.851 ± 0.470 mm。
2. **D1小样本**：九、六、三、一个月预算；共同39个测试窗口。不是完整109日评价。
3. **D1消融**：固定响应模型的受控消融口径，不能把其完整参照行改成独立PRFM主表结果。
4. **D1实测未来温度**：PRFM及八个条件基线；共同60个测试日；使用统一总响应训练的PRFM结果。
5. **D2**：独立STPM–PRFM配对、七位置、完整60日测试；同时提供合成数据生成和有限元系数相关代码。
