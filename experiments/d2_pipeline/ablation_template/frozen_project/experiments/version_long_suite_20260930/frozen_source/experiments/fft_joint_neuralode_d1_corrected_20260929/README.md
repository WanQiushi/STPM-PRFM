# LF相位、末端翘曲与BW瘪环联合修正

本实验从上一轮分阶段BW–FFT–Neural ODE建立独立版本，不覆盖历史代码。

- 相位：在实测MF温度和各支座响应之间加入0.25–4 h可学习的一阶热惯性，初始1.25 h；有效结构温度同时驱动可逆项和BW状态。
- LF翘曲：过去一天趋势只作为ODE特征，不再无条件加到每个时间步；增加LF相对路径、一阶差分和起点连续性损失。
- 瘪环：BW预训练阶段冻结直接可逆增益`k`，增加MF一阶差分和环面积权重；联合阶段继续保留总预测、FFT解耦及独立LF/MF损失。
- FFT边界只在最终联合阶段解冻，仍可接收预测误差梯度。
- seed 2024；测试集封存。
