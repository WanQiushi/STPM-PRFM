# 分阶段BW–FFT–Neural ODE实验

目标是验证上一轮MF预测退化为直线是否来自总位移损失绕过BW记忆。

- 阶段A（1–15轮）：冻结LF、FFT边界和直接可逆项`k*u`，只训练BW初值、`s/beta/gamma`和神经残差；目标为MF点误差、滞回面积误差与ODE残差。
- 阶段B（16–30轮）：解冻除FFT边界外的预测网络，训练总位移、LF/MF分量、滞回面积、Stage1和ODE损失。
- 阶段C（31轮起）：解冻FFT边界，以小学习率联合微调；分别保存全程最佳和阶段C最佳。
- 训练使用所有满足30天严格因果历史和未来实测温度条件的候选起点；验证仍使用原固定起点，测试封存。
- seed2024一组。停止条件只在阶段C按验证总位移MSE计算，避免阶段A/B提前终止。

基础模型复用`experiments/fft_joint_neuralode_d1_20260929/model.py`，未覆盖上一轮代码。
